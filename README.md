# monitoring_desktop

# 사용자 데스크탑 앱 이용시간 및 제한해주는 앱



##주요 기능 목록
기능: 원하는 앱 이름 입력
설명: 사용자의 데스크탐 앱에서 원하는 앱 이름 입력

기능: 앱 시간 감시(client)
설명: psutil을 이용하여 실시간으로 사용자의 앱 사용 감시
